First public release of Thaldren Engine, a reimplementation of the Total Annihilation 3.1 engine.

**No game data is included.** You need your own installed copy of Total Annihilation 3.1 (the Steam release works). Not affiliated with or endorsed by the owners of Total Annihilation.

### Download
`thaldren-engine-v0.1.0-windows-x64.zip` (Windows 10/11, 64-bit). Its SHA-256 is in the attached `.sha256` file.

### Running
Unzip, then either copy `ta_play.exe` and the three DLLs into your Total Annihilation folder and run it there, or set `TA_DIR` in `run.bat` and run that.

### State of this release
- Every routine of the original program is ported or recorded as not applicable (see `docs/parity/COVERAGE.md`).
- The simulation matches the original tick for tick on the recorded test games; multiplayer speaks the original's DirectPlay wire protocol.
- Many menu and interface details are built from the original's code but not yet pixel-compared; see the parity documents for each item's status.
- Windows x64 only for now.
